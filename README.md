# YSave Mornings: mobile app

Expo SDK 58 · React Native · TypeScript. A time-budgeted daily planner: plan tomorrow's tasks, run them
with a countdown, and collect a marble in the day's jar for each one you finish.

Design documents (spec, architecture, data model, domain rules, design system, decisions, roadmap) and the
per-milestone build reports are in [`docs/`](docs/README.md).

```bash
npm install
npx expo start        # scan the QR code with Expo Go
npm run typecheck && npm run lint && npm test
```
